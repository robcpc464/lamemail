# Contributing

## Pull requests

At this time pull requests are not accepted. Every one is closed unread,
without exception and however good it is: lamemail stays the work of one
author. Please do not put work into one.

## Bug reports and ideas

Both are welcome as issues.

A bug report is most useful with:

- the commit you built (`git rev-parse --short HEAD`)
- your distribution and, for the UI, the Qt version (`qmake6 -query
  QT_VERSION`)
- what you did, what happened and what you expected
- the mail provider, when it concerns syncing or sending
- for a mail that is shown wrong: a message that shows it

## Security

A vulnerability is not reported as an issue, see
[`SECURITY.md`](SECURITY.md).
